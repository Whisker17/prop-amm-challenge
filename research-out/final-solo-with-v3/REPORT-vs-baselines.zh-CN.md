# 相对被动基准（Uniswap V2 / V3）的对比

## 必须先读的口径说明

- DODO 与 Flashbots 使用**同一个零延迟 oracle**：每步先量化发布价格，再套利、再零售。
- Uniswap V2 与 Uniswap V3 是**被动 AMM，不消费任何外部 oracle**。这是曲线本身的性质，不是本实验的配置选择。
- 因此「相对 Uni 的差异」**同时包含 oracle 重定价优势与曲率差异**，不能整体归因于曲率。下文的拆分一节给出两者的量级。
- 下表中的多个显著结果**不是多个独立实验**：它们共用同一批 seed、同一条价格路径、同一份订单流，并且共用同一个 baseline，因此彼此高度相关。不要把「N 个结果显著」当作 N 次独立验证。

生成结果的 benchmark commit（**二进制的** commit，不是写报告时的 HEAD）：`26fe1f1b651c3b93d91cce954919f1eb0016efcc`，provenance 一致。

模拟 1000 次 × 10000 步。

## Sanity check：full-range V3 vs UniV2

两者都是被动、零手续费、同等期初资本，因此逐 seed 的 netEdge 差**应当很小**——但**不是 0，本节也不断言它是 0**。已实测的两项真实残差：同一状态下单笔报价最大差 **1693 wei**；允许各自独立演化后，400 笔内状态漂移最大 **484 wei**（见 `univ3_vs_univ2_continuous`）。

### 硬性 gate（判定只由这三项决定）

只有可以从构造本身证明的性质才进入判定：

* full-range 仓位覆盖整个 tick 域，**不可能**因区间容量不足而拒单；
* canonical capacity probe **不得**走到 revert 分支，否则该订单的容量根本没被测到；
* 移植的报价函数**不得**走到 revert 分支。

| gate | 值 | 要求 |
| --- | --- | --- |
| 判定 | **PASS** | — |
| full-range 容量不足订单数 | 0 | = 0 |
| capacity probe revert 数 | 0 | = 0 |
| curve revert 数 | 0 | = 0 |


### 残差诊断（**不是上界，不进入判定**）

> **下面的 reference scale 是启发式量纲参考，不是数学上界。**残差低于它**本身不证明任何东西**。三处构造假设未经证明，其中至少两处在一般情况下不成立：

1. `δ²` 形式假设两个搜索都停在光滑目标的**内部驻点**。实际目标既不光滑也非无约束——它按 nano 向下取整，是阶梯函数；最优点还经常落在边界上（`α = 0` 或 `1`，或套利量被 `MIN_INPUT` 夹住）。边界最优处一阶项不消失，误差是 `O(δ)` 而非 `O(δ²)`。
2. `arb_notional × δ²` 的系数是**断言的，不是推导的**；没有任何论证说明套利目标的曲率被自身名义额界住。
3. 量化项用的是 `final_fair_price`（收盘价），**不是**交易实际发生价格的上界；一条收在低位的路径会低估它。

此外它完全忽略误差传播：两个池一旦分岔就各自独立演化，逐笔上界求和不构成对复利轨迹的上界。

列出它只是为了让读者不必心算运行规模，就能看出残差是 1e-2 还是 1e2。诊断的**判别力**由 `tests/report_artefacts.rs` 里的 mutation 测试给出：把报价刻意压低 1 bp，残差会比真实曲线高出若干数量级。

本 benchmark 只对比曲线报价本身（curve-only）。池级别的风控与准入不在范围内，也未被实现：Flashbots 的 targetY emergency lock（`_isTargetYLocked`，仅作用于 swap 路径，upstream 的 quoteXtoY / quoteYtoX 本身也不经过它）、Mantle 的 notional / reserve / inventory deviation 上限、以及余额与授权检查，全部不参与。

`curve_reverts` 只统计被移植的**报价函数**在非退化输入下走到 revert 分支（溢出 / 下溢 / 除零）的次数。它为 0 表示定价数学在整个运行中没有触发 revert，**不等于**一笔完整的链上 swap 会成功——池级别的风控、余额与授权检查不在本 benchmark 范围内。
